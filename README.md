# Vinheria Agnello - Checkpoint 02

## Descrição

Sistema de avaliação de estoque e tendência de vinhos, feito em JavaScript com `prompt()` e `alert()`. Nele é possível cadastrar vários vinhos em sequência (nome, safra e quantidade em estoque). O sistema valida as entradas, avisa quando o estoque está baixo (menos de 5), classifica o vinho como jovem, amadurecido ou antigo e, ao final, mostra o total de cadastros, a quantidade de vinhos com estoque baixo e o vinho com a safra mais antiga.
